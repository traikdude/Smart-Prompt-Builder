# 🎉 Release v2.13.0 - Smart-Prompt-Builder

## 📅 Release Information
- **Date:** Monday, April 14, 2026 at 12:13 AM EDT
- **Tag:** v2.13.0
- **Branch:** main

## 📋 Summary
Phase 7.1 — Self-Improving Feedback Loop. This minor release closes the RLHF data collection loop into an active **Retrieval-Augmented Generation (RAG)** engine. The backend now dynamically injects high-rated historical examples into the Gemini system prompt at request time, enabling real-time behavioral improvement without model retraining.

## 🔄 Changes in This Release

### ✨ Added — Backend (`backend/main.py`)
- **`RLHF_CACHE` singleton** — global in-memory dict mapping `selected_lens → [high-rated examples]`
- **`refresh_rlhf_cache()`** — async background task that reads the RLHF Google Sheet on startup, filters `rating == 1` rows, and populates the cache (non-blocking, fires via `asyncio.create_task`)
- **`build_system_instruction()`** — prompt injection engine that retrieves up to 3 gold-standard examples per active lens and prepends a structured `[GOLD STANDARD EXAMPLE FOR {lens}]` block to the Gemini `system_instruction`
- **`active_lenses: Optional[List[str]]`** field added to `BatchGenerateRequest` and `StreamGenerateRequest` Pydantic models
- `generate_single_prompt()` now accepts and forwards `sys_instruction` into a typed `config: Dict[str, Any]` for every Gemini `generate_content` call

### ✨ Added — Frontend (`App.tsx`)
- **`active_lenses` payload** — the JSON body sent to `/api/v1/generate/batch` now includes `active_lenses: formatLenses.map(fl => fl.label)`, enabling the backend RAG lookup to be lens-aware

### ✨ Added — Frontend (`components/FormatSuggestions.tsx`)
- **FormatSuggestions copilot** — keyword-based, non-intrusive chip row that suggests optimal `OUTPUT_CATEGORIES` and sub-formats as the user types (triggers after 5+ characters)

### ✨ Added — Frontend (`components/PromptForm.tsx`)
- Injected `FormatSuggestions` component below the main input area

### 🔧 Changed
- `generate_single_prompt()` signature extended with optional `sys_instruction` parameter (backward-compatible)
- `batch_generate` route now calls `build_system_instruction` before spawning coroutines
- `stream_generate` route now merges RLHF examples with any existing `system_instruction` via `build_system_instruction`
- Pylint 10.00/10 maintained ✅ (all new code conforms to C0301, C0303, W0603, W0718, E1101 rules)

### 🏗️ Architecture: RAG Feedback Loop
```
User Thumbs Up (rating=1)
  → POST /api/v1/feedback → Google Sheet (6-column row)
    → Next Cold Start: refresh_rlhf_cache() reads Sheet
      → RLHF_CACHE[lens] = [high-rated (prompt, output) pairs]
        → build_system_instruction() injects into system_instruction
          → Gemini sees gold-standard examples → improved output
```
